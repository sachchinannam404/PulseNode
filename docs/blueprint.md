# **App Name**: PulseNode

## Core Features:

- Patient EMR & Portal: A centralized dashboard for electronic medical records, including medical history, digital test results, and direct patient access to prescriptions.
- Intelligent Roster Management: Dynamic shift scheduling with role-based access control for clinicians and administrative staff, integrated with payroll markers.
- Unified Billing & Insurance: Automated invoice generation with integrated claims processing for major insurers and a secure digital payment gateway.
- Live Pharmacy & Inventory: Real-time stock tracking for medications and high-value medical devices with automated restock alerting via API triggers.
- Diagnostics Sync Hub: Seamless digital bridge for lab results (MRI, X-Ray, pathology) allowing direct physician viewing and status tracking.
- Bed Capacity Forecasting Tool: An AI-powered tool that analyzes patient flow to predict bed availability and readmission rates for better resource allocation.
- Compliance & Audit Logging: System-wide tracking to maintain HIPAA standards, ensuring every record access event is logged in the backend database.

## Style Guidelines:

- Primary color: Clinical Indigo (#375399) evoking trust and professional precision in a light color scheme.
- Background color: Sterile Soft Blue (#F9FAFB), heavily desaturated to provide a clean, modern medical aesthetic.
- Accent color: Oceanic Cyan (#32A2B4) for key action buttons and status indicators, providing high contrast against the indigo primary.
- Headline font: 'Space Grotesk' (sans-serif) for a high-tech, precise architectural feel. Body font: 'Inter' (sans-serif) for maximum legibility in complex data environments.
- Thin-line, geometric medical iconography that adheres to a minimal, technical style for clarity on high-density screens.
- A modular, dashboard-first layout with high information density but clearly partitioned blocks for fast clinical decision-making.
- Quiet, functional transitions like subtle fades and horizontal sliding drawers for patient records to maintain a calm UI atmosphere.
